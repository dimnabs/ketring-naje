# Naje Nutrition

Website katering bergizi berbasis Next.js. Commit awal proyek berisi fondasi aplikasi dan landing page responsif untuk memperkenalkan layanan, menu mingguan, serta pilihan paket.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Lucide Icons

## Menjalankan aplikasi

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).

## Pemeriksaan kualitas

```bash
npm run lint
npm run typecheck
npm run build
```

Fitur akun pelanggan, autentikasi, database, pembayaran, dan dashboard operasional akan dikembangkan pada iterasi berikutnya.
